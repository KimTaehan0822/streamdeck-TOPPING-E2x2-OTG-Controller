Controller for TOPPING E2x2 OTG Stream Deck プラグイン 取扱説明書

2026-11-14 (v0.1.3)

Elgato Stream Deck のキーとダイヤルで TOPPING E2x2 OTG のミキサーを操作するプラグインです。デバイスと USB(HID)で直接通信します。キーごとに Mix とチャンネルを決めておけば、TOPPING アプリにどの Mix が表示されていても、決めた対象だけが動きます。

作者: 김탄2 (Kimtan2)

インストールファイルTOPPING-E2x2-OTG.streamDeckPlugin

ダイヤルのアクション(VU dial、Pan dial、디지털 게인 다이얼)は Stream Deck + でのみ使えます。キーのアクションはすべての Stream Deck で使えます。

最初に必ずお読みください(制限)

このプラグインで変えた値は TOPPING アプリの画面には表示されません。また、アプリがその値を上書きすることがあります。

デバイスは現在のミキサーの値を返しません。そのためプラグインは値を自分で覚えておき、TOPPING アプリのワークスペースファイル(.TPwork)を読んで値を合わせます。アプリで Mix 画面を切り替えたり、アプリを再起動したりすると、アプリは自分が覚えている値をデバイスに送り直します。Stream Deck で変えた値をアプリにも合わせるには、TOPPING アプリ再起動キーを使ってください(下記参照)。このとき TOPPING アプリが 2〜3 秒止まってから起動し直します。

ステップ 1: プラグインのインストール

  1. TOPPING-E2x2-OTG.streamDeckPlugin をダブルクリックします。

  2. Stream Deck アプリがインストールするか聞いてきたらインストールを押します。上書きするか聞かれた場合もインストールを選びます。既存のキー設定はそのまま残ります。

  3. 右側のアクション一覧に Controller for TOPPING E2x2 OTG カテゴリーがあることを確認します。

  4. どれかのアクションをキーに置いてクリックすると、下に設定画面が出ます。一番上の言語で 한국어、English、日本語 を選べます。選んだ言語はすべてのアクションに適用されます。

ステップ 2: アプリとプラグインの値を合わせる

プラグインは TOPPING アプリが開いているワークスペースを読んで始まります。アプリでワークスペースが開いていれば、特に何もする必要はありません。キーに SETUP と表示されている場合は、まだ読めるワークスペースがありません。次のどちらかを行ってください。

  • アプリでワークスペースを開く: TOPPING アプリ上部の Workspace 一覧からワークスペースを選びます。数秒でキーがその値に変わります。

  • Workspace の読み込みキーを押す: 下の「Workspace キー」を参考に読み込みキーを作って押します。

アプリで値を変えたら、アプリでワークスペースを保存してください。保存するとプラグインが新しい値を読み直します。

ステップ 3: 最初のキーを作る

Mix A の Playback 1/2 の音量を、キー 1 回で 1 dB ずつ上げる例です。

  1. アクション一覧から Fader をキーにドラッグします。

  2. 設定画面で対象を Mix チャンネル、Mix を A、チャンネルを Playback 1/2 にします。

  3. モードはステップ調整のままにし、調整幅 (dB、負の数 = 下げる)に 1 を入れます。

  4. 押すたびに 1 dB ずつ上がります。下げるキーは同じ方法で -1 を入れて作ります。

キー 2 つを上下に並べて使うなら Button fader (2 keys) が便利です。2 つのキーにまたがってフェーダーが描かれ、押し続けると動き続けます。

対象の選び方

Fader、Button fader、VU dial、Mute は対象で次の 3 つから 1 つを選びます。

対象意味
Mix チャンネルMix A〜D の中のチャンネル 1 つ(IN、Playback、Loopback など)。Mix とチャンネルを選びます
ループバックLoop 1/2、3/4、5/6
出力Out 1/2、Mobile Out、S/PDIF

出力が鳴らしている Mix に追従(フェーダー、フェーダー 2キー、VU ダイヤル、Mute、Pan、Pan ダイヤル、LINK): Mix 一覧のいちばん下で選び、追従する出力(Out 1/2、Mobile Out、S/PDIF)を決めます。キーはその出力のソースがいま Mix A〜D のどれかに合わせて、その Mix のチャンネルを操作し、キーの Mix 表示も変わります。Mix ごとに音量が違うため、出力が別の Mix に切り替わると音が急に大きくなることがあります。切り替える前に音量を下げ、聞くときは注意してください。出力のソースが Mix でないときは、キーに NOT A MIX と表示され、何もしません。

LINK がオフのチャンネルは L と R が別々に動きます。このとき Mute、Solo、Pan のキーは左右で両方 (ペア)、L のみ、R のみを選べます。音量のキー、Button fader、VU dial は常に両方に働きます。

すべてのチャンネルキーは名前欄に入れた文字をキーに表示します。空欄なら既定の名前になります(最大 24 文字)。

Output Source Select

対象で音を送る先(ループバックまたは出力)を選び、モードで選び方を決めます。

  • MIX A〜D を順に切り替え: 押すたびに MIX A → B → C → D と変わります。

  • 選んだソースを順に切り替え: ソースでチェックしたものだけを順に切り替えます。

  • 2つのソースを切り替え: ソース 1 と ソース 2 を行き来します。

Workspace キー

モードで読み込みか保存を選びます。

  • 読み込み: ワークスペース一覧から保存済みのワークスペースを選びます。キーを押すとその値をデバイスに送り、すべてのキーがその値に変わります。最後に読み込んだキーはオンのように表示されます。

  • 保存: 新しいワークスペース名を入れます。キーを押すと現在の値をその名前のワークスペースファイルに保存します。保存したワークスペースは TOPPING アプリを再起動するとアプリの一覧にも出ます。

  • デバイスにも記録(保存モード、初期設定はオン): オンにすると、保存のときに値をデバイス本体にも記録します。インターフェースの電源を切って入れ直してもその値が残ります。TOPPING アプリのダウンロードと同じ働きです。オフにするとファイルだけを保存します。

  • TOPPINGアプリを再起動して合わせる(両モード、初期設定はオン): 保存や読み込みのあと、TOPPING アプリを強制終了し、そのワークスペースを開いた状態で通知領域に起動し直します。アプリは起動時にそのワークスペースをデバイスに送るので、アプリの画面・デバイス・キーがすべて同じ値になります。アプリは 2〜3 秒止まり、アプリで変えて保存していない値は失われます。不要ならオフにしてください。

保存のときの注意

  • TOPPINGアプリを再起動して合わせるをオフにしたキーは、TOPPING アプリがいま開いているワークスペースの名前では保存しません。アプリが終了するときに自分の値で上書きしてしまうためです。設定画面に「保存できません」と出たら別の名前を入れてください。オンにしたキーはアプリを強制終了するので上書きは起きず、その名前でも保存します。

  • 同じ名前のワークスペースがあれば上書きします。直前のファイルひとつだけが同じフォルダーに隠しファイル .E2X2_OTG_<名前>.TPwork.bak として残ります。バックアップは名前ごとにひとつで、上書きするたびにその直前の値に置き換わります。

  • デバイスが接続されていないときはファイルだけを保存し、キーに ⚠ を表示して、設定画面でそのことを知らせます。

アプリから直接デバイスに記録する方法: TOPPING アプリ上部のワークスペース名の右にあるダウンロードアイコンを押し、一番上の項目(現在のワークスペースを保存してデバイスにダウンロード)を選んで OK を押します。

TOPPING アプリ再起動キー

TOPPING アプリは終了するときに覚えている値をワークスペースファイルに保存し、起動するときにそのファイルをデバイスに送ります。そのため Stream Deck で変えた値は、アプリを終了して起動し直すと戻ってしまいます。このキーはアプリを強制終了(終了時の保存なし)して起動し直し、このずれをなくします。モードで選びます。

  • TOPPINGアプリの設定を合わせる(初期設定): いまのキーの値をアプリが開いているワークスペースに保存してから、アプリを再起動します。Stream Deck の値が基準になります。そのワークスペースに保存されていた値は上書きされます。直前の値ひとつだけがバックアップとして残ります。

  • 直前に戻す: アプリが開いているワークスペースを最後の保存の直前の値(バックアップ)に戻してから、アプリを再起動します。もう一度押すと新しい値に戻ります。バックアップがなければキーに ⚠ を表示します。

  • TOPPINGアプリを再起動: 保存せずにアプリだけを再起動します。アプリに保存されたワークスペースの値が基準になり、デバイスとキーもその値に戻ります。

アプリが起動していなければ、キーを押したときに起動します。アプリが 5 秒以内に閉じなければ何も変えず、キーに ⚠ を表示します。

レベルメーター

  • メーターは音が出ているときだけ動きます。

  • メーターはチャンネルごとにあります。Mix チャンネルはそのチャンネル、ループバックはループバック、出力は出力のメーターを表示します。

  • OTG 入力もメーターを表示します。

既知の制限

  • 入力の Solo はデバイスで何の効果もありません。

  • 音量は最大 +12 dB、デジタルゲインは 0 〜 +20 dB です。LINK 状態のパンも TOPPING アプリと同じように動きます。

  • 48V はオンにするとき設定画面に警告を出すだけです。キーを押すとすぐオンになるので、コンデンサーマイク以外の機器をつないだままオンにしないよう注意してください。

  • デバイスで直接押した INST、モニタリング、48V、ヘッドホンゲインのボタンはキーにもすぐ反映されます。モニタリングノブ(Input ↔ Playback)はまだ反映しません。

  • プラグインはデバイスの USB ドライバーを変更しません。公式ドライバーで使える HID 通信だけを使います。
