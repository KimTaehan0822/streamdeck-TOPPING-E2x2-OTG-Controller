Controller for TOPPING E2x2 OTG Stream Deck Plugin Manual

2026-11-14 (v0.1.3)

This plugin controls the TOPPING E2x2 OTG mixer from Elgato Stream Deck keys and dials. It talks to the device directly over USB (HID). Each key is set to a Mix and a channel, and it moves only that target, whatever Mix the TOPPING app is showing.

Made by: Kimtan2

Read this first (limits)

Values the plugin changes do not show in the TOPPING app, and the app can overwrite them.

The device does not report its current mixer values. So the plugin keeps the values itself and matches them by reading the TOPPING app's workspace file (.TPwork). When you switch the Mix view in the app or restart the app, the app sends its own values to the device again. To make the app match the values set on Stream Deck, use the TOPPING app restart key (see below). The TOPPING app then closes and opens again for 2-3 seconds.

Step 1: Install the plugin

  1. Double-click TOPPING-E2x2-OTG.streamDeckPlugin.

  2. When the Stream Deck app asks, click Install. If it asks to replace an installed version, choose Install too. Your existing keys are kept.

  3. Check that the Controller for TOPPING E2x2 OTG category is in the action list on the right.

  4. Put any action on a key and click it to open its settings below. At the top, Language switches between 한국어, English and 日本語. The choice applies to every action.

Step 2: Match the app and the plugin

The plugin starts from the workspace the TOPPING app has open, so if the app has a workspace open there is nothing to do. If the keys show SETUP, no workspace has been read yet. Then do one of these:

  • Open a workspace in the app: pick one in the Workspace list at the top of the TOPPING app. The keys follow within a few seconds.

  • Press a Workspace load key: make a load key (see "Workspace key" below) and press it.

After changing values in the app, save the workspace in the app. The plugin then reads the new values.

Step 3: Make your first key

This example raises the Playback 1/2 volume in Mix A by 1 dB per press.

  1. Drag Fader from the action list onto a key.

  2. In the settings, set Target to Mix channel, Mix to A and Channel to Playback 1/2.

  3. Leave Mode on Step and enter 1 in Step (dB, negative = down).

  4. Each press raises the volume by 1 dB. Make a key that lowers it the same way, with -1.

For two keys stacked together, Button fader (2 keys) is handier: it draws one fader across both keys and keeps moving while you hold a key.

Choosing a target

Fader, Button fader, VU dial and Mute pick one of three under Target.

TargetMeaning
Mix channelOne channel in Mix A to D (IN, Playback, Loopback and so on). You pick the Mix and the channel
LoopbackLoop 1/2, 3/4, 5/6
OutputOut 1/2, Mobile Out, S/PDIF

A channel with LINK off has separate L and R. Then Mute, Solo and Pan keys can pick Both (pair), L only or R only under Side. Volume keys, Button fader and VU dial always act on both sides.

Every channel key shows the text in its Name field. Leave it empty for the default name (24 characters at most).

Output Source Select

Pick where the sound goes (a loopback or an output) under Target, and how it changes under Mode.

  • Cycle MIX A-D: each press goes MIX A → B → C → D.

  • Cycle chosen sources: steps through only the ones ticked in Sources.

  • Toggle between two: switches between Source 1 and Source 2.

Workspace key

Pick Load or Save under Mode.

  • Load: pick a saved workspace in the Workspace list. Pressing the key sends its values to the device and every key follows. The key you loaded last looks switched on.

  • Save: enter a New workspace name. Pressing the key saves the current values as a workspace file with that name. It appears in the TOPPING app's list after the app restarts.

  • Also store on the device (Save mode, on by default): when on, saving also stores the values in the device itself, so they stay after the interface is switched off and on. This does the same as the TOPPING app's download. When off, only the file is saved.

  • Restart the TOPPING app to match (both modes, on by default): after saving or loading, the TOPPING app is force-closed and started again in the tray with that workspace open. On start the app sends that workspace to the device, so the app, the device and the keys all show the same values. The app is gone for 2-3 seconds, and changes made in the app but not saved there are lost. Turn it off if you do not want this.

When saving

  • With Restart the TOPPING app to match off, the key does not save under the name of the workspace the TOPPING app has open, because the app writes its own values over it when it exits. If the settings show "Cannot save", enter another name. With the option on, the app is force-closed before it can write over the file, so that name is allowed.

  • A workspace with the same name is replaced. Only the version just before stays in the same folder as the hidden file .E2X2_OTG_<name>.TPwork.bak. There is one backup per name, and each save replaces it with the version it overwrote.

  • If the device is not connected, only the file is saved; the key shows ⚠ and the settings say so.

Storing on the device from the app: in the TOPPING app, click the download icon right of the workspace name at the top, pick the first option (save the current workspace and download to the device) and click OK.

TOPPING app restart key

The TOPPING app saves the values it remembers to its workspace file when it exits, and sends that file to the device when it starts. So values set on Stream Deck jump back after the app is closed and opened. This key force-closes the app (with no exit save) and starts it again to remove that mismatch. Pick it in Mode:

  • Match TOPPING app settings (default): saves the current key values into the workspace the app has open, then restarts the app. The Stream Deck values win. The values saved in that workspace are overwritten. Only the version just before is kept as a backup.

  • Undo to the previous version: puts back the version of the app's open workspace from before the last save (the backup), then restarts the app. Press again to return to the newer version. With no backup the key shows ⚠.

  • Restart TOPPING app: restarts the app without saving. The workspace saved in the app wins, and the device and the keys go back to it.

If the app was not running, the key starts it. If the app does not close within 5 seconds, nothing is changed and the key shows ⚠.

Level meters

  • Meters move only while sound is playing.

  • Each channel has its own meter: a Mix channel shows that channel, a loopback shows the loopback, an output shows the output.

  • The OTG input shows its meter too.

Known limits

  • Solo on an input has no effect on the device.

  • Volume goes up to +12 dB and digital gain is 0 to +20 dB. Pan on a linked channel moves exactly as in the TOPPING app.

  • 48V only shows a warning in the settings. Pressing the key turns it on at once, so do not turn it on with anything other than a condenser microphone connected.

  • INST, monitoring, 48V and headphone gain pressed on the device show on the keys at once. The monitoring knob (Input ↔ Playback) is not followed yet.

  • The plugin does not change the device's USB driver. It uses only the HID communication the official driver allows.
