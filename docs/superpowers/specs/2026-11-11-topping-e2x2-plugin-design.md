# TOPPING E2x2 OTG 스트림덱 플러그인 (설계)

## 왜
TOPPING E2x2 OTG 믹서를 스트림덱 키와 다이얼로 조절하고 싶다. 이미 있는 "TOPPING Deck" 플러그인(`io.github.pianit.topping-deck`)은 다음 문제가 있다.
- 장비와 직접 통신하지 않는다. 따로 도는 파이썬 도우미(`topping_addon.py`, `127.0.0.1:8765`)에 부탁하는 방식인데, 그 도우미가 배포 파일에 들어 있지 않다.
- 토핑 앱 화면에 지금 보이는 Mix만 조절할 수 있다.
- 레벨미터가 없다.

그래서 사용자의 토탈믹스 플러그인(`streamdeck-rme-totalmix`)과 같은 구성으로 새 플러그인을 만든다. 기능 목록은 토핑 플러그인에서 가져오고, 장비와는 USB로 직접 통신한다.

## 목표
- 키·다이얼마다 대상을 고정한다. 토핑 앱 화면에 어떤 Mix가 떠 있든 정해 둔 대상만 움직인다.
- 레벨미터를 보여 준다(VU 다이얼).
- 원래 토핑 플러그인·도우미, 토탈믹스 플러그인과 함께 설치해서 쓸 수 있다(플러그인 ID가 다르다).
- 토탈믹스 플러그인과 같은 화면 모양과 조작감을 쓴다(키 그림, 다이얼 레이아웃, 누르고 있으면 반복, 설정 화면).

### 대상 (공통)
VU 다이얼, 페이더(2버튼), 페이더, Mute, Solo는 아래 중 하나를 대상으로 고른다.

| 대상 종류 | 고르는 것 | 예시 |
|---|---|---|
| Mix 채널 | Mix(A/B/C/D) + 인풋/플레이백 채널 | Mix B의 PB 1/2 |
| 루프백 | Loopback 1/2, 3/4, 5/6 | Loopback 3/4 |
| 출력 | 출력(마스터) | OUT 1/2 |

Mix 채널 후보(원래 토핑 플러그인 기준): IN 1+2, IN OTG, PB 1/2, PB 3/4, PB 5/6, PB 7/8.
출력 후보: OUT 1/2, Mobile OUT(원래 플러그인의 "OUT OTG"), S/PDIF OUT(원래 플러그인의 "OUT 5/6"으로 추정, USB 분석 때 확인).

### 액션 목록
| 액션 | 하는 일 | 토탈믹스 플러그인의 대응 액션 |
|---|---|---|
| Mute | 대상의 음소거 켜기/끄기 | Mute |
| Solo | 대상의 솔로 켜기/끄기 (Mute와 같은 대상 고르기) | Solo |
| Input option | IN 1~2의 48V, INST, Ø(위상 반전) | Input option |
| 디지털 게인 | 입력 디지털 게인 키 | Input gain |
| 디지털 게인 다이얼 | 입력 디지털 게인 다이얼 | Gain Dial |
| VU 다이얼 | 돌리면 볼륨, 누르면 Mute, 레벨미터 표시 | VU Dial |
| 페이더(2버튼) | 볼륨 −/+ 두 키 | Fader(2-Button) |
| 페이더 | 볼륨을 정해 둔 값으로 맞추기 / 한 단계씩 | Fader |
| Pan / Pan 다이얼 | Mix 채널의 Pan | Pan / Pan Dial |
| 소스 선택 | 루프백 채널과 출력에 보낼 소리 고르기 (아래) | Output loopback |
| LINK | Mix별 채널 스테레오 묶기 | (토핑에만 있음) |
| 출력 컨트롤룸 | 모니터 Gain, HP/TRS/AUX 켜기·끄기 | Control Room |
| Workspace | 작업 공간 저장·불러오기 (아래) | Snapshot |

### 소스 선택
- 대상: Loopback 1/2, 3/4, 5/6, OUT 1/2, Mobile OUT, S/PDIF OUT.
- 후보: 인풋, 플레이백, Mix A~D. 종류를 섞어서 고를 수 있다.
- 방식 세 가지:
  1. **Mix 번갈아 가기:** 누를 때마다 Mix A → B → C → D → A
  2. **고른 것 안에서 번갈아 가기:** 체크한 후보만 차례로 (예: IN 1 → PB 1/2 → Mix B)
  3. **토글:** 두 후보 사이를 오간다 (예: PB 1/2 ↔ Mix A)
- 키에는 지금 선택된 소스를 표시한다.
- 장비가 실제로 어떤 후보를 허락하는지는 USB 분석 때 확인한다. 장비가 받지 않는 후보는 설정 화면에서 빼거나 막는다.

### 토핑 앱과의 값 맞추기 (사용자 결정: C안, 2026-11-11)
USB 분석 결과 장치는 믹서 값을 돌려주지 않는다. 그래서 다음과 같이 한다.
- 플러그인은 믹서 전체 값을 직접 기억하고 USB(HID)로 보낸다. 앱 화면 조종(UI 자동화)이나 USB 엿듣기는 하지 않는다.
- 플러그인이 시작할 때, 그리고 앱의 작업 공간 파일이 바뀔 때마다 파일을 다시 읽어서 값을 맞춘다. 파일은 `C:\Program Files\TOPPING Pro\TOPPING Professional Control Center\E2X2_OTG\*.TPwork`이고, 앱이 마지막으로 연 것은 `sound_card_workspace_file.TPconfig`의 `LastWorkspaceOpened_E2x2_OTG`에 적혀 있다.
- 남는 한계: 스트림덱으로 바꾼 값은 앱 화면에 보이지 않는다. 앱에서 Mix 화면을 바꾸거나 앱을 다시 켜면 앱이 기억하는 값으로 되돌아간다.
- **이 한계를 눈에 띄게 설명한다.** README 맨 앞, 그리고 각 설정 화면 위쪽에 경고 문구를 둔다. 권장 사용법을 함께 적는다.
  1. 토핑 앱에서 볼륨을 한 번 맞추고 작업 공간을 저장한다.
  2. 토핑 앱 위쪽의 다운로드 아이콘(Workspace 이름 오른쪽)을 누르고 **"Save the current workspace and download to the device"** 를 골라 OK를 누른다. 작업 공간이 저장되고 장치에도 기록된다.
  3. 스트림덱의 Workspace 불러오기 키로 그 작업 공간을 불러온다. 이 키를 누르면 장치와 플러그인이 같은 값으로 맞춰진다.
  4. 그 뒤로는 스트림덱 위주로 쓴다.
- 설명에는 위 다운로드 창의 스크린샷(빨간 표시)을 함께 넣는다.
- 확정: 사용자가 2026-11-11 이 설계를 확정했다.

### Workspace 키
- **불러오기 (사용자 요청):** 키마다 작업 공간 파일 하나를 고른다. 누르면 그 파일의 값을 장치에 모두 보내고(앱이 켜질 때 보내는 것과 같은 묶음), 플러그인이 기억하는 값도 그 파일로 바꾼다.
- **저장 (내 판단):** 플러그인이 지금 기억하는 값을 같은 형식의 새 작업 공간 파일로 저장한다. 토핑 앱의 작업 공간 목록에서도 열 수 있다. 앱이 쓰고 있는 파일은 덮어쓰지 않는다(앱이 끌 때 자기 값으로 다시 덮어쓰기 때문).
- 작업 공간 폴더는 일반 사용자 권한으로 쓸 수 있다(2026-11-11 확인).

### 화면 모양 (사용자 결정, 2026-11-11)
- VU 미터, 키, 다이얼 화면은 토탈믹스 플러그인 모양을 복사하지 않는다. **토핑 앱(TOPPING Professional Control Center)의 디자인을 참고해서 전체를 새로 그린다.** 참고 화면: `docs/images/download-to-device.png`
- 스크린샷에서 뽑은 색: 바탕 `#1F1F1F`, 패널 `#2D2D2D`, 켜진 버튼 파랑 `#4261C0`, 선택된 Mix 글자 초록 `#73CB67`, 페이더 손잡이 `#D8D8D8`, 꺼진 버튼은 어두운 회색 바탕에 흰 글자.
- 미터는 앱처럼 가는 세로 막대 2개(L/R)와 눈금(0, -6, -12, -24, -∞)을 쓴다. 채널 이름은 앱처럼 위쪽 회색 이름표에 넣는다.
- 키 크기, 글자 맞춤(두 줄 맞추기 등) 같은 그리기 기술은 토탈믹스 플러그인의 `render/svg.ts` 방식을 다시 써도 된다. 바뀌는 건 모양과 색이다.

## 하지 않는 것 (지금은)
- Group, Global FX, FX parameter, Layout preset, TotalMix window: 토핑에 해당 기능이 없다.
- MON, 샘플레이트, 버퍼 크기, 값 표시 키: 일단 뺀다.
- Mix A~D 화면 전환 키: 키마다 Mix를 고정하므로 필요 없다.
- 맥(macOS) 지원.
- 원래 토핑 도우미와의 연동.

사용자는 실제 장비에서 동작하는 걸 본 뒤 기능을 빼거나 고칠 지침을 다시 준다. 처음부터 완벽한 목록을 만들려고 하지 않는다.

## 제약
- **USB 통신 형식을 아직 모른다.** 장비는 2026-11-11 저녁에 도착하고, 그때 Wireshark + USBPcap으로 토핑 공식 앱(TOPPING Professional Control Center V1.13)의 통신을 기록해서 알아낸다. 그 전에는 USB 계층 코드를 쓰지 않는다.
- 토핑 앱과 내 플러그인이 같은 USB 장치를 동시에 쓸 수 있는지 모른다. 저녁에 확인한다.
- 토핑 앱이 장비 값을 계속 다시 읽는지 모른다. 다시 읽지 않으면 스트림덱으로 바꾼 값이 앱에 안 보이고, 앱이 옛 값을 다시 보내 덮어쓸 수 있다. 장비 본체의 노브 값은 앱에 반영되지 않는다는 자료가 있다.
- 윈도우 10 이상, Stream Deck 앱 6.6 이상, Node 20, `@elgato/streamdeck` 3.0.4 (토탈믹스 플러그인과 같다).

## 방법 (선택한 것: A)
**A. 새 프로젝트로 따로 만든다.**
- 위치: `streamdeck-topping-e2x2`
- 플러그인 ID: `com.haeunga0822.topping-e2x2`
- 토탈믹스 플러그인에서 복사해 쓰는 부분: `runtime/`(기본 액션, 누르고 있으면 반복, 다시 그리기), `render/svg.ts`의 글자 맞춤 도구(모양은 토핑 앱 스타일로 새로 그림, 아래 "화면 모양"), `ui/`의 설정 화면 틀(`sdpi-components.js`, `common.js`), `layouts/strip.json`, rollup·tsconfig·테스트 방식(`node --test`), 빌드·패키지 스크립트.
- 새로 만드는 부분: USB 통신 계층(토탈믹스의 `osc/` 자리), 토핑 장비 제어(토탈믹스의 `protocol/controller.ts` 자리), E2x2 OTG 채널 모델(`model/` 자리), 위 액션들.
- 토탈믹스 플러그인 저장소는 건드리지 않는다.

검토했다가 뺀 방법:
- **B. 토탈믹스 플러그인 안에 장비 종류로 추가:** 코드는 한 곳에 있지만, 배포 중인 1.0.1이 복잡해지고 고장 날 위험이 생긴다. "새로 만들기"라는 요청과도 맞지 않는다.
- **C. 공통 부분을 패키지로 떼어 두 플러그인이 함께 쓰기:** 토탈믹스 플러그인부터 크게 고쳐야 한다. 나중에 복사한 코드를 관리하기 귀찮아지면 그때 옮긴다.

대가: 같은 코드가 두 곳에 생긴다. 토탈믹스 쪽에서 고친 그리기 코드는 손으로 옮겨야 한다.

## 진행 순서
1. **USB 분석 (저녁, 장비 필요):** 아래 표를 채운다. 결과는 이 저장소의 `docs/usb-protocol.md`에 적는다.
2. 분석 결과로 USB 라이브러리를 고른다. HID면 `node-hid`, 아니면 `usb`(libusb/WinUSB).
3. 이 설계와 분석 결과로 구현 계획을 쓰고 사용자 확인을 받는다.
4. 구현하고 실제 장비로 동작을 확인한다.

### USB 분석에서 알아낼 것
| 알아낼 것 | 확인 방법 |
|---|---|
| 장치가 쓰는 USB 방식(HID / 벤더 전용 / 오디오 클래스 컨트롤) | 장치 관리자, USBPcap 기록 |
| Mix 채널 볼륨 신호에 Mix 번호가 들어 있는지 | 앱에서 Mix A의 PB 1/2, Mix B의 PB 1/2를 차례로 움직인다 |
| 출력 마스터 볼륨, Mute, Solo, Pan, LINK, 48V, INST, Ø, 디지털 게인 신호 | 앱에서 하나씩 바꾼다 |
| 루프백·출력 소스 선택 신호와 고를 수 있는 후보 | 앱에서 하나씩 바꾼다 |
| 모니터 Gain, HP/TRS/AUX, Workspace 신호 | 앱에서 하나씩 바꾼다 |
| 현재 값을 읽는 방법(앱이 시작할 때 무엇을 묻는지) | 앱을 켜는 순간을 기록한다 |
| 레벨미터 값이 오는 신호와 주기 | 소리를 내면서 기록한다 |
| 앱과 플러그인 동시 접속 가능 여부 (안 되면 어느 쪽을 우선할지 이때 사용자와 정한다) | 앱을 켠 채 테스트 프로그램으로 장치를 연다 |
| LINK 끔 상태에서 L/R 채널 신호(볼륨, Pan, Mute)가 따로 가는지 | LINK를 끄고 L/R을 따로 움직인다 |
| 앱이 장비 값을 다시 읽는지 | USB로 값을 바꾼 뒤 앱 화면을 본다 |

## 사용자가 정한 것
- 새 프로젝트로 따로 만든다(A).
- 장비와 USB로 직접 통신한다. 원래 토핑 플러그인·도우미도 계속 같이 쓴다.
- 키마다 Mix(A~D)+채널을 고정한다. 출력 마스터 볼륨도 따로 조절한다.
- VU 다이얼, 페이더(2버튼), 페이더, Mute, Solo의 대상: Mix 채널 / 루프백 / 출력.
- Input option에 Ø를 넣는다. 입력 게인은 "디지털 게인"으로 표시한다.
- 컨트롤룸은 "출력 컨트롤룸"으로 따로 표시한다.
- LINK는 Mix별로 적용하는 별도 액션이다.
- 루프백과 출력의 소스 후보는 인풋·플레이백·Mix를 섞어서 고른다(방식 3가지).
- 토탈믹스 플러그인과 겹치는 기능은 모두 넣고, 나중에 동작을 보고 다시 고른다.

## 내가 정한 것 (사용자가 바꿀 수 있음)
- 루프백 소스 선택과 출력 소스 선택을 "소스 선택" 액션 하나로 합친다.
- 출력 컨트롤룸 = 모니터 Gain + HP/TRS/AUX 켜기·끄기.
- 폴더 이름 `streamdeck-topping-e2x2`, 플러그인 ID `com.haeunga0822.topping-e2x2`.
- **USB 드라이버는 바꾸지 않는다.** Zadig 같은 도구로 WinUSB 드라이버를 깔면 토핑 공식 드라이버, 토핑 앱, 원래 도우미가 멈출 수 있다. 사용자는 그것들을 계속 쓰려고 한다. 공식 드라이버를 그대로 둔 채 쓸 수 있는 길(HID, 오디오 클래스 컨트롤 등)만 쓴다. 그 길이 없으면 구현 전에 사용자에게 다시 묻는다.
- ~~값이 엇갈리면 장비 값이 이긴다.~~ USB 분석 결과 장비는 값을 돌려주지 않는다(`docs/usb-protocol.md`). 그래서 플러그인이 믹서 전체 값(교차점, 입력 배율, 소스, 버튼)을 직접 기억한다. 시작할 때는 토핑 앱의 작업 공간 파일에서 값을 읽어 온다. 충돌 처리 방식은 사용자와 다시 정한다.
- (사용자 결정) **LINK가 꺼지면 스테레오 채널은 모노 채널 두 개가 되고, 각각 따로 Pan한다.** 대상을 고를 때 짝 전체 / L / R을 고를 수 있다. LINK가 켜져 있으면 짝 전체로 움직인다.
- (내 판단) LINK가 꺼진 모노 채널은 Pan뿐 아니라 볼륨, Mute, Solo도 L/R을 따로 대상으로 고를 수 있다. 원래 토핑 플러그인에도 `vol_l/vol_r`, `mute_l/mute_r`이 있다.
- ~~장비에 Workspace 불러오기 명령이 없으면 Snapshot은 뺀다.~~ 사용자 요청으로 작업 공간 파일을 읽어 값을 모두 보내는 방식으로 만든다(위 Workspace 키).
- 설정 화면 문구는 토탈믹스 플러그인처럼 영어 기본으로 하고, 액션 이름에 "디지털 게인", "출력 컨트롤룸"처럼 사용자가 정한 이름을 쓴다.

## 빌더에게 맡기는 것
- 파일을 어떻게 나눌지, 토탈믹스 코드에서 무엇을 얼마나 복사할지.
- 키 그림 세부 모양(토탈믹스 플러그인 모양을 따른다).
- USB 재연결 간격, 레벨미터 갱신 주기(분석 결과에 맞춘다).
